# Seackays Ventures Website

A simple static personal website ready for GitHub and Vercel.

## Files

- `index.html` — website content
- `styles.css` — design and layout
- `script.js` — automatically updates the copyright year
- `images/` — add your own photographs here

## Upload to GitHub

1. Create a new GitHub repository.
2. Click **Add file** → **Upload files**.
3. Upload every file and folder in this package.
4. Click **Commit changes**.

## Deploy with Vercel

1. In Vercel, click **Add New** → **Project**.
2. Import the GitHub repository.
3. Select **Other** as the framework.
4. Leave the build command and output directory blank.
5. Click **Deploy**.

## Add your domain

In Vercel, open the project and go to:

**Settings** → **Domains**

Add your domain and follow the DNS instructions shown by Vercel.

## Before publishing

Search `index.html` for:

- `hello@example.com`
- `Instagram`
- `LinkedIn`

Replace these with your real contact details.

The current photographs are temporary images from Unsplash. Replace them with your own photographs when ready.
